Settings

Compare each game against

Every game is graded first, then scored by where that grade places it among other games — so the set it is compared against decides the number. The season so far pools every game played up to the day you are viewing, which lets a team’s own results be ranked against each other. That day alone compares a game only with the games played beside it, so the same win scores lower on a crowded night than a quiet one, and two of a team’s wins can come out in the wrong order.

Score against

The grader has no notion of divisions, and records only compare across teams with overlapping opponents, so a result from a corner of the schedule that never meets D1 is measured on a different ruler. This feed carries only D1 games and D1 games against outside opposition — no games between two non‑D1 teams — so games with a D1 team, the default, and every game played currently pick out the same set; both are kept so they stay distinguishable if that changes. Games between D1 teams is stricter: the 8.8% of results that cross the line neither score a team nor sit in the field. Excluded games still count in their own teams’ records; what changes is which results are scored and what they are measured against.

Victors gate over top

To qualify you must have beaten somebody worth beating, and that team must qualify too — the rule repeats until the set stops changing. A team that does not is struck through where it stands. It stays off through the opening fortnight and tightens as the season fills in, because it needs cross‑conference results to work. It never changes a rating or an order; it only decides who is struck through.

Opponent weighting

Scales every game by how good the opponent turned out to be, so a win over a poor team counts for less and a loss to a poor team costs more. Each half is pulled toward its own worst end — a win toward the halfway mark, a loss toward zero — so every win still finishes above every loss. Hover any score on a team page for the arithmetic. Balanced, the default, keeps every win above every loss; strong bites harder and drops that rule. Because the weight depends on the ranking it is solved rather than calculated, taking about a dozen passes. Turn it off for the plainer figure, with nothing laid on top of what the season says.

How this works

What this is. Every game is graded by what happened next: your result, then how your opponent did across the rest of its season with this game removed, then how their opponents did in turn. That grade is turned into a 0–100 score by where it places among every game played so far this season, and a team's rating is the average of its games. No preseason poll, no margin of victory, no votes. (The gear icon can score each game against its own day alone instead — the original method.)

Why rankings move backwards. A November win is not settled in November. It gains value if the team you beat keeps winning and loses value if they collapse. Drag the date slider and you are watching the season reinterpret itself. Click any team to see each of its games and how their worth has shifted: the small line beside each game is that game alone, re‑graded after every day since it was played. Hover it for the day‑by‑day figures.

Seeing the raw order. Slates lays out every result from a single day in exactly the order the grader puts them — wins above losses, then by opponent — with both opponent numbers and the score beside each one. The ranking is just those scores averaged per team, so this is the table everything else is built from.
